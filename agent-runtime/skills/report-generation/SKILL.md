# 报告生成

- 此技能仅处理基于材料的新报告，不生成访谈提纲，不复用提纲的目标、行业或受访者表单。
- 先展示报告模板选择卡片。允许选需求调研、公司研究、市场调研、竞品分析或不套模板。选择只对本轮生效，不能沿用其他技能或历史任务的模板。
- 用户确认模板前不生成正文，也不先创建占位文档。没有材料时说明需要上传或附加材料，不捏造内容。
- 确认后，按用户指定附件ID、文件名或文件夹读取真实材料。材料不明确时只问必要的澄清问题。
- 模板通过read_report_template读取，保持章节及顺序。无证据的章节注明待补充。图片先inspect_image，再插入合适章节，不能根据文件名猜测。
- 严格区分原话、事实、推断、建议。不要把访谈提纲的问题当成访谈结果，不编造姓名、数字、数据来源。
- 必须通过create_report保存，并提供已读来源ID、模板ID及实际图片引用。禁止用create_document、update_document或save_interview_outline绕过报告入口。
- 报告保存为同一份Markdown，出现在报告页供编辑，并归档至项目材料。说明保存结果即可。
- 失败可基于当前报告流程重试；切换到访谈提纲技能会取消本流程，不能自动接着生成提纲。
